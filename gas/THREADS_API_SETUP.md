# Threads API トークン取得マニュアル

このツールが Threads に投稿するには、Meta（Facebook 社）が提供する **Threads Graph API** のアクセストークンが必要です。
このマニュアルは「Meta for Developers の操作経験ゼロ」を前提に、画面の操作手順を順番にまとめています。

> **所要時間の目安**：30 〜 60 分（初回のアプリ作成・申請承認待ちを含む）
>
> **取得するもの**：
> 1. **THREADS_USER_ID**（数字）
> 2. **THREADS_ACCESS_TOKEN**（長期トークン、約 60 日有効）

---

## 0. 事前準備

| 項目 | 説明 |
|------|------|
| Threads アカウント | 投稿先のアカウント。Instagram と連携済みであること |
| Facebook アカウント | Meta for Developers にログインするため |
| ブラウザ | PC のブラウザ推奨（スマホでは画面が崩れることがあります） |

> ⚠️ Threads アカウントは Instagram と紐づいている必要があります。スマホの Threads アプリ →「プロフィール」→「設定」→「アカウント」から Instagram と連携されているか確認してください。

---

## 1. Meta for Developers にアプリを登録

### 1-1. 開発者アカウントの作成

1. <https://developers.facebook.com/> にアクセス
2. 右上「**ログイン**」から Facebook アカウントでログイン
3. 初回は「開発者として登録」のフローに進みます。電話番号認証 → 利用規約同意 → 完了

📸 **撮るスクリーンショット**：開発者アカウント登録完了画面（後で確認用）

### 1-2. 新規アプリ作成

1. 上部メニュー「**マイアプリ**」→「**アプリを作成**」
2. ユースケース選択画面で「**その他**」を選んで「次へ」
3. アプリタイプは「**ビジネス**」を選択して「次へ」
4. アプリの詳細：
   - アプリ名：任意（例：`Threads 予約投稿ツール`）
   - アプリの連絡先メール：自分のメールアドレス
   - ビジネスポートフォリオ：「ビジネスポートフォリオなし」で OK
5. 「**アプリを作成**」をクリック
6. 本人確認（パスワード再入力）

📸 **撮るスクリーンショット**：作成されたアプリのダッシュボード（左サイドバーが見える状態）

---

## 2. Threads API プロダクトを追加

1. 作成したアプリのダッシュボード左サイドバーから「**プロダクトを追加**」を探す
2. 「**Threads API**」を見つけて「**設定**」をクリック
   - 表示されない場合は「すべての製品」→ Threads で検索
3. 利用規約に同意

### 2-1. リダイレクト URI を設定

Threads API は OAuth でトークンを発行するため、リダイレクト URI を 1 つ登録する必要があります。
個人利用なら以下のダミー URL を入れれば OK です：

```
https://localhost/
```

1. 左サイドバー「Threads API」→「**Use cases / Settings**」内
2. 「**Redirect Callback URLs**」欄に上記 URL を入力 → 保存

📸 **撮るスクリーンショット**：リダイレクト URI 入力後の設定画面

---

## 3. Threads アカウントを連携してトークンを発行

### 3-1. アクセストークン生成画面を開く

1. アプリのダッシュボード →「Threads API」→「**Use cases**」
2. 「**Generate access tokens**」セクションを探す
3. 「**Add account**」または「**アカウントを追加**」ボタンをクリック

### 3-2. Threads アカウントの認可

1. ポップアップで Threads（Instagram）にログイン
2. 「このアプリに以下の権限を与えますか？」と表示されるので、必要な権限にチェック：
   - `threads_basic`（必須）
   - `threads_content_publish`（**投稿に必須**）
   - `threads_manage_replies`（任意）
   - `threads_read_replies`（任意）
3. 「**許可**」をクリック

### 3-3. 短期トークンを取得

1. 認可後、画面に **Access Token**（短期トークン、有効期限 1 時間）が表示される
2. 「**Copy**」ボタンで全文コピー → メモ帳など安全な場所に保存

📸 **撮るスクリーンショット**：トークン表示画面（トークン本体は隠してから保存推奨）

> ⚠️ 短期トークンは 1 時間で切れるため、すぐに次のステップで「長期トークン」に変換します。

---

## 4. 短期トークン → 長期トークンに変換

長期トークンは **約 60 日有効** です。以下のリクエストを送って変換します。

### 4-1. ブラウザで変換 URL を開く

ブラウザのアドレスバーに以下を貼り付け、`{SHORT_LIVED_TOKEN}` 部分を 3-3 でコピーした短期トークンに置き換えて Enter：

```
https://graph.threads.net/access_token?grant_type=th_exchange_token&client_secret={APP_SECRET}&access_token={SHORT_LIVED_TOKEN}
```

#### `{APP_SECRET}` の取得

1. アプリのダッシュボード左サイドバー「**アプリの設定 → ベーシック**」
2. 「**App Secret**」横の「**表示**」ボタン → パスワード再入力
3. 表示された値をコピーし、上記 URL の `{APP_SECRET}` を置き換える

### 4-2. 結果

ブラウザに JSON が表示されます：

```json
{
  "access_token": "THQVJX...（とても長い文字列）",
  "token_type": "bearer",
  "expires_in": 5183944
}
```

この `access_token` の値が **長期アクセストークン** です。コピーして保存してください。
これが設定シートの `THREADS_ACCESS_TOKEN` に入る値です。

📸 **撮るスクリーンショット**：JSON 結果画面（トークン本体は隠す）

---

## 5. THREADS_USER_ID の取得

### 5-1. ブラウザで以下にアクセス

`{LONG_LIVED_TOKEN}` を 4-2 で取得した長期トークンに置き換えて：

```
https://graph.threads.net/v1.0/me?fields=id,username&access_token={LONG_LIVED_TOKEN}
```

### 5-2. 結果

```json
{
  "id": "1234567890123456",
  "username": "あなたの_threads_username"
}
```

この `id` の値が **THREADS_USER_ID** です。コピーして保存してください。

---

## 6. スプレッドシートの「設定」シートに入力

| キー | 値 |
|------|------|
| THREADS_USER_ID | 5-2 で取得した `id` |
| THREADS_ACCESS_TOKEN | 4-2 で取得した `access_token` |

入力後、スプレッドシートのメニュー「**Threads ツール → 設定を確認**」で疎通テストを行ってください。
「設定 OK」と表示されれば成功です。

---

## 7. トークンの再取得（60 日ごと）

長期トークンの有効期限が近づいたら、以下のいずれかで延長 / 再取得します。

### 方法 A. 既存の長期トークンをリフレッシュ（推奨）

長期トークンは **発行から 24 時間以上経過** していれば、以下でリフレッシュ可能です（さらに 60 日延長）：

```
https://graph.threads.net/refresh_access_token?grant_type=th_refresh_token&access_token={CURRENT_LONG_LIVED_TOKEN}
```

返ってきた新しい `access_token` を設定シートに上書きしてください。

### 方法 B. ゼロから再発行

期限切れになった場合は §3 から手順を繰り返してください。

> 💡 **おすすめ運用**：カレンダーに「Threads トークンリフレッシュ」を 50 日後にリマインダー登録しておくと安心です。

## 8. 困ったときは

### 「Threads API」が製品一覧に見つからない
- アプリタイプを「ビジネス」で作成しているか再確認
- 一部のアカウントでは Threads API がまだ利用できない地域があります（数日後に再試行 / 別 Facebook アカウントを試す）

### `(#10) Application does not have permission for this action`
- アプリに `threads_content_publish` 権限が付与されていません
- §3-2 のアカウント連携をやり直し、`threads_content_publish` にチェックを入れてください

### `Invalid OAuth access token`
- トークンが無効。スペースが混入していないか、コピー漏れがないか確認
- それでもダメなら新しいトークンを発行

### `User has not authorized application` 系エラー
- 認可した Threads アカウントとトークンを使うアカウントが一致しているか確認

### App Review について
- **個人利用なら App Review 不要** です。自分のアカウントに対してのみ投稿する範囲なら開発モードのまま使えます
- 他人のアカウントに代理投稿させる用途で配布する場合は別途レビュー申請が必要です

---

## 9. セキュリティ上の注意

- アクセストークンは **パスワードと同じ重要度** です。SNS や GitHub の公開リポジトリに貼らないでください
- スプレッドシートの共有設定にも注意（共有相手はトークンを閲覧できます）
- 不要になったトークンは Meta for Developers の管理画面から失効させましょう
