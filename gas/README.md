# Threads 予約投稿ツール — セットアップガイド

Google スプレッドシートで投稿予約を管理し、指定時刻に Threads へ自動投稿するツールです。
ホスティング不要・ランニングコスト 0 円で動きます。

> **このマニュアルの読み方**
> 上から順に作業すれば動きます。途中で詰まったら「困ったときは」を参照してください。
> Threads API のトークン取得方法は別ファイル `THREADS_API_SETUP.md` を参照してください。

---

## 0. このツールでできること

- Google スプレッドシートに「日付・時・分・本文」を書いておくと、その時刻に自動で Threads に投稿されます
- ステータス列が `投稿済み` に変わり、投稿 URL も記録されます
- 失敗した場合はエラー内容も記録されます

## 2. セットアップ手順

### Step 1. スプレッドシートを新規作成

1. ブラウザで <https://sheets.new> を開く
2. ファイル名を `Threads 予約投稿ツール` に変更（任意ですが分かりやすい名前を推奨）

### Step 2. Apps Script エディタを開く

1. 上部メニュー **「拡張機能」→「Apps Script」** をクリック
2. 新しいタブで Apps Script エディタが開きます

### Step 3. コードを貼り付ける

このリポジトリの `gas/` フォルダに以下のファイルがあります。**ファイルごとに同じ名前** で Apps Script エディタにコピペしてください。

| Apps Script 上のファイル名 | 中身 |
|---|---|
| `Code.gs` | `gas/Code.gs` の内容 |
| `Config.gs` | `gas/Config.gs` の内容 |
| `Sheet.gs` | `gas/Sheet.gs` の内容 |
| `ThreadsApi.gs` | `gas/ThreadsApi.gs` の内容 |
| `Logger.gs` | `gas/Logger.gs` の内容 |
| `Trigger.gs` | `gas/Trigger.gs` の内容 |
| `appsscript.json` | `gas/appsscript.json` の内容 |

**ファイル追加方法：**
- エディタ左サイドバー「ファイル」横の **＋ボタン → 「スクリプト」** で新規 .gs を追加
- ファイル名を入力（`.gs` は自動付与なので不要）
- 中身をコピペ

**`appsscript.json` を表示するには：**
- エディタ上部の **歯車アイコン（プロジェクトの設定）** をクリック
- 「`appsscript.json` マニフェスト ファイルをエディタで表示する」にチェック
- 左サイドバーに `appsscript.json` が現れるので、内容を貼り付けて上書き

最後に **保存（💾 アイコンまたは Ctrl+S）** を忘れずに。

### Step 4. 初期セットアップを実行

1. 元のスプレッドシートのタブに戻る
2. ブラウザを **F5 で再読み込み**
3. 上部メニューに「**Threads ツール**」が表示されるはず
4. 「Threads ツール」→「**初期セットアップ**」をクリック
5. 初回は権限承認ダイアログが出ます：
   - 「権限を確認」をクリック
   - Google アカウントを選択
   - 「このアプリは確認されていません」と出たら「**詳細**」→「（プロジェクト名）に移動（安全ではないページ）」
   - 「許可」をクリック
6. 「セットアップ完了」と出れば成功

実行後、`設定` `投稿予約` `ログ` の 3 シートが自動作成されます。

### Step 5. Threads API トークンを設定

1. 別ファイル `THREADS_API_SETUP.md` の手順で **THREADS_USER_ID** と **THREADS_ACCESS_TOKEN** を取得
2. スプレッドシートの **「設定」シート** を開く
3. それぞれの「値」欄に貼り付け

| キー | 値 |
|------|------|
| THREADS_USER_ID | 取得したユーザー ID |
| THREADS_ACCESS_TOKEN | 取得した長期アクセストークン |

### Step 6. 接続テスト

1. メニュー「**Threads ツール → 設定を確認**」をクリック
2. 「設定 OK」と表示され username が出れば成功

## 3. 使い方

### 投稿を予約する

「投稿予約」シートに 1 行追加：

| 日付 | 時 | 分 | 本文 |
|------|----|----|------|
| 2026/5/12 | 17 | 48 | テスト投稿です |

- ステータス列は空欄でも OK（自動的に `待機中` 扱いになります）
- ID 列は空欄のままでも OK（自動採番されます）
- 1 行ごとに 1 投稿。複数行まとめて入れても大丈夫です

### 自動実行

「初期セットアップ」を実行した時点で、**1 分ごとに自動で投稿チェック** が走ります。
予約時刻に達した行から順に投稿されます。

### 手動で動かす

待ちたくない時は「**Threads ツール → 今すぐ実行**」で即時実行できます。
（テスト時に便利）

### 自動実行を止める

「**Threads ツール → トリガー解除**」をクリック。
シートのデータは消えません。再開したい時は「初期セットアップ」をもう一度実行。

---

## 4. ステータスの意味

| ステータス | 意味 |
|-----------|------|
| 待機中 / 空欄 | 未投稿。予約時刻が来たら投稿されます |
| 投稿済み | 投稿成功。投稿日時・投稿 ID・投稿 URL が記録されます |
| 失敗 | エラー発生。J 列「エラー」に詳細が出ます |
| スキップ | 予約時刻から 24 時間以上経過（古すぎる予約の暴発を防止） |

「失敗」の行を再投稿したい場合は、ステータスを `待機中` に戻すか空欄にしてください。

---

## 5. 動作確認手順（最初の 1 回はこの通りに）

1. 設定シートにトークンを入力済みであること
2. 投稿予約シートに 1 行追加：
   - 日付：今日
   - 時・分：**今から 2〜3 分後** の時刻
   - 本文：`Threads ツール動作確認`
3. メニュー「Threads ツール → 今すぐ実行」をクリック
   - まだ予約時刻前ならステータスは変わりません（正常）
4. 予約時刻を過ぎたら、もう一度「今すぐ実行」
5. ステータスが「投稿済み」に変わり、投稿 URL が入れば成功
6. その URL をクリックして実際に Threads 上で投稿が表示されればテスト完了

## 6. 困ったときは

### メニュー「Threads ツール」が出ない
- スプレッドシートを **F5 再読み込み** してください
- それでも出ない場合、Apps Script エディタで `Code.gs` の `onOpen` 関数を選んで実行ボタン（▶）を押すと表示されます

### 「設定不備」と出る
- 「設定」シートの THREADS_USER_ID と THREADS_ACCESS_TOKEN が空欄でないか確認

### 「設定エラー HTTP 400 / 401」と出る
- トークンの有効期限切れ、または USER_ID とトークンの組み合わせが違う可能性
- `THREADS_API_SETUP.md` でトークンを再取得してください

### 「文字数超過」と出る
- 本文が 500 文字を超えています。短くしてください

### ステータスが「待機中」のまま動かない
- メニュー「初期セットアップ」をやり直すとトリガーが再登録されます
- 1 分待っても動かない場合は Apps Script エディタの「実行数」タブでエラーを確認

### トークンの有効期限
- Threads の長期アクセストークンは **60 日** で期限切れになります
- 切れる前に `THREADS_API_SETUP.md` の手順で再取得 → 設定シートを更新

## 8. 仕様メモ

- 1 分ごとにトリガー実行（無料枠で十分動作）
- API 呼び出しは最大 3 回リトライ（1s, 3s, 5s）
- レート制限 (HTTP 429) は次回実行に持ち越し
- 24 時間以上遅延した予約は「スキップ」扱い
- Phase 1 はテキスト投稿のみ（画像/動画は将来対応予定）
