音声ファイルの無音カット＋フィラー除去を行う。

## やること

ユーザーが音声ファイルをアップロードまたはパスを指定したら：

1. ファイルパスを特定する（アップロードされたファイルは `/root/.claude/uploads/` 以下にある）
2. 以下のコマンドを実行する：
   ```
   python3 /home/user/LP-/audio_clean.py "<ファイルパス>"
   ```
3. 完了したら出力ファイルのパスと削除した秒数を報告する

## 処理内容
- 0.3秒以上の無音を自動カット
- フィラーワード除去（えー、あの、まあ、そのー、えっと、なんか、uh、um、like など）
- 出力は元ファイルと同じ場所に `_cleaned` をつけて保存

## ユーザーがMacのファイルを処理したい場合

Macのターミナルで以下を実行するよう案内する（スペースの後にファイルをドラッグ＆ドロップ）：
```
python3 ~/audio_clean.py 
```

出力ファイルは元ファイルと同じフォルダに `_cleaned.mp3` として保存される。
